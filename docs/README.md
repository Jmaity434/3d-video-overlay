# Library Documentation

This directory contains the planning and engineering documentation for
`3d-video-overlay` / `video3doverlay`.

- [Product Requirements Document](PRD.md): product scope, goals, users,
  acceptance criteria, and release risks.
- [Technical Requirements Document](TRD.md): runtime, packaging, error,
  compatibility, and test requirements.
- [Architecture and Design Description](ADD.md): components, scene graph,
  lifecycle, decisions, and extension points.
- [API Reference](API.md): public functions, class behavior, validation
  helpers, exceptions, and controls.
- [CI/CD and Distribution Plan](CICD-DISTRIBUTION.md): current CI, quality
  gates, versioning, release workflow, and PyPI strategy.
- [Five-Library Comparison](LIBRARY-COMPARISON.md): the requested comparison
  of Panda3D, Pygame + PyOpenGL, and OpenCV + ModernGL.

The documents describe the current `0.1.0` implementation and identify future
work separately where the capability does not yet exist.
